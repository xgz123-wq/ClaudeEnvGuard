# Claude 日常启用

> 整理日期：2026-10-01
> 适用范围：本机已有 Claude 配置

## 启动与检查

### 启动顺序

1. **打开代理**：启动 Clash Verge。
2. **确认模式**：使用 `Rule` 规则模式，TUN 开启，系统代理关闭。
3. **确认节点**：`ACCOUNT-US` 使用自己选定的节点。
4. **程序检查**：双击桌面 `Claude-环境一键总检`。
5. **网页检查**：程序检查通过后，在实际使用的专用浏览器核对出口、DNS、WebRTC、IPv6、语言和时区。
6. **启动应用**：由自己选择所需桌面图标。

### 检查结果处理

| 检查结果 | 接下来做什么 |
|---|---|
| `PASS` | 查看其余检查项 |
| `WARN` | 查看具体原因，必须处理防护相关警告 |
| `FAIL` | 停止启动，交给 AI 排查 |
| `MANUAL` | 完成对应的真实网页人工检查 |

**Anthropic 网段阻断**：总检会核对 `160.79.104.0/23` 的系统出站规则；规则缺失或配置变化时显示 `FAIL`，按[网段直连阻断说明](Anthropic网段直连阻断.md)处理。

### 验收边界

- **节点变更**：更换节点后重新建立连接并复验。
- **入口隔离**：一个浏览器的检查结果不能替另一个浏览器放行。
- **历史结果**：以前通过不代表今天正常。

## 桌面入口与维护

| 桌面图标 | 作用 |
|---|---|
| `Claude-环境一键总检` | 检查配置，可能打开专用 Chrome 检测页 |
| `Claude-五项自检` | Clash 通道五项检查，结束后会打开账号 1 专用 Chrome |
| `Claude-英文浏览器` | 检查通过后打开 Claude Desktop |
| 对应账号的专用 Chrome | 使用该账号独立的浏览器数据 |

- **维护默认**：AI 更新或检查时不启动 Claude Desktop 或 Claude Code。
- **更新**：在本项目说「更新 Claude Desktop」「更新 Claude Code CLI」或「我已手动更新，请同步」。
