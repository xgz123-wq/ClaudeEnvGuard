# 环境检查说明

「检查环境」会按顺序执行以下 9 项检测，任何一项都可点击日志查看原始结果。

## 1. 系统时区
- 读取当前系统时区（Windows 下为 tzutil 时区名）。
- 与「目标地区配置」中选择的地区对比：一致为「正常」，不一致为「需注意」。

## 2. 系统/浏览器语言
- 系统语言：Windows 读取 WinUserLanguageList 首语言。
- Chrome / Edge 语言：读取浏览器 User Data 下的 Local State / Preferences。
- 与目标地区语言（us→en-US，cn→zh-CN）对比。

## 3. DNS 泄露检测
- 读取本机生效的 IPv4 DNS 服务器列表。
- 建议配合代理的「远程 DNS / 防 DNS 旁路」功能使用，避免运营商 DNS 暴露真实地区。

## 4. ANTHROPIC_BASE_URL
- 检查用户级 / 机器级持久环境变量以及当前进程环境。
- 使用官方服务时应保持「未设置」；已设置第三方中转会被标记「需注意」。

## 5. IPv6
- Windows：枚举所有网卡的 ms_tcpip6 绑定状态。
- 启用「禁用 IPv6」时，任何仍启用的网卡都会标记「需注意」。

## 6. WebRTC (Chrome) / 7. WebRTC (Edge)
- 读取浏览器策略 WebRtcIPHandling。
- 值为 disable_non_proxied_udp（禁用非代理 UDP）时为「正常」，否则提示可能泄露真实 IP。
- 「一键配置美国」会自动写入该策略；「一键配置中国」会还原。

## 8. 系统代理
- Windows：读取 Internet Settings 注册表（ProxyEnable / ProxyServer / PAC）。
- 目标地区为美国时应已启用代理；国内直连模式下未启用为正常。

## 9. Claude 连通性
- 分别探测 https://claude.ai 与 https://api.anthropic.com 的可达性。
- 两个都可达为「正常」；只有一个可达为「需注意」；都不可达为「需注意」（此时请检查代理）。

## 顶部「网络出口信息」
- 通过 ipinfo.io（兜底 ip-api.com）查询当前公网出口。
- 同时显示系统代理地址；如果代理未生效，这里的 IP 就是真实出口。
