# 软件操作说明

## 快速上手
1. 在「目标地区配置」选择目标地区（默认 us_west），按需勾选「禁用 IPv6」。
2. 点「检查环境」查看 9 项检测结果；全部「正常」即可放心使用 Claude。
3. 有「需注意」项时，点「一键配置环境」自动修复（按所选地区执行），
   或手动点「一键配置美国 / 一键配置中国」。

## 按钮一览

### 检查与配置
- **检查环境**：重新执行全部检测，并刷新顶部网络出口信息。
- **一键配置环境**：按当前选择的地区自动配置（时区、语言、系统代理、IPv6、WebRTC 策略、DNS 缓存）。需要管理员权限。
- **一键配置中国 / 一键配置美国**：与上面相同，但固定为对应模式。
  - 美国模式：启用系统代理（端口见 app/resources/settings.json，默认 10808）、禁用 IPv6、写入 WebRTC 防泄露策略、清除 ANTHROPIC_BASE_URL。
  - 中国模式：关闭系统代理、恢复 IPv6、还原 WebRTC 策略。

### 清理（都会先备份再删除，删除后需重新登录）
- **清理Claude Code凭据**：删除 ~/.claude/.credentials.json 并清理 .claude.json 中的登录会话字段。
- **清理Claude桌面端**：删除 %APPDATA%\Claude 与 Claude Desktop 的配置库。
- **清理Claude网页版**：删除 Chrome / Edge 中 claude.ai、anthropic.com 的 Cookie。
  - 浏览器必须完全关闭，否则数据库锁定会失败。
- 备份位置：%LOCALAPPDATA%\ClaudeEnvGuard\backups\<时间戳>\

### 底部工具
- **环境变量检查 / 时区语言检查 / DNS 解析检查**：只读小工具，结果弹窗展示。
- **重启电脑**：60 秒后重启（shutdown /r /t 60）。
- **环境检查说明 / 软件操作说明**：打开本文档。

## 常见问题
- **提权弹窗**：一键配置需要管理员权限，请在 UAC 弹窗中选择「是」。
- **代理端口**：软件不会替你装代理；本工具只把系统代理指向 127.0.0.1:端口，
  请确保本机代理客户端（v2rayN / Clash 等）已运行。端口可在
  app/resources/settings.json 中修改（v2rayN 默认 10808，Clash 默认 7890）。
- **日志位置**：%LOCALAPPDATA%\ClaudeEnvGuard\logs\（配置脚本）；
  界面下方「执行日志」实时显示本程序输出。
