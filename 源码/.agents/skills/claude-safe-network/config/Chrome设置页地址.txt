将地址复制到专用 Chrome 的地址栏后回车；普通 HTML 一般不能直接打开 chrome:// 地址。

chrome://version
核对「命令行」的代理端口、--user-data-dir 和「个人资料路径」。这是本方案首要检查页。

chrome://settings/security
查看安全 DNS；保留浏览器安全防护。开关状态不证明 DNS 出口，需要配合检测与连接记录。

chrome://settings/content/location
查看位置权限，按真实使用需要管理；本教程不自动修改隐私设置。

chrome://settings/languages
按实际使用习惯设置语言，不把语言/时区伪装作为防封步骤。

chrome://settings/system
查看退出 Chrome 后继续运行后台应用的选项。休眠前确认相关浏览器确实退出。

https://ip.net.coffee/claude/
从专用浏览器测试出口、DNS、WebRTC、IPv6；不要用普通浏览器结果替它作证。

界面名称以当前 Chrome 版本为准；本文件是操作地址清单，不是配置已经生效的证明。
